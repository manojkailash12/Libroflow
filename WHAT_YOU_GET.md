3. **auth-me.js** - Get current user information
4. **auth-forgot-password.js** - Send OTP for password reset
5. **auth-reset-password.js** - Reset password with OTP
6. **books.js** - Browse and search books
7. **dashboard-stats.js** - Student statistics
8. **transactions-borrow.js** - Borrow books
9. **transactions-return.js** - Return books with fine calculation
10. **transactions-my-history.js** - User transaction history
11. **librarian-stats.js** - Library statistics
12. **librarian-books.js** - CRUD operations for books
13. **librarian-users.js** - User management
14. **librarian-analytics.js** - Analytics and insights
15. **librarian-recent-transactions.js** - Recent activity
16. **librarian-export.js** - Excel and PDF exports

### Utility Modules
